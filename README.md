# Dental Appointment Self-Management Platform

<p align="left">
   <img src="https://img.shields.io/badge/STATUS-DONE-green">
</p>

This project is a web application designed for a dental clinic, enabling patients to easily book and track their appointments online. It provides a user-friendly interface where patients can select their desired service, view available time slots and confirm appointments without the need to contact the clinic directly.

### Technologies Used
This website was built using HTML, CSS and JavaScript.

### Libraries Used
Bootstrap: v5.3.x
Used for responsive design, providing pre-built components and layout utilities to create a mobile-first, modern interface for the platform.

Luxon: v3.3.x
A powerful library for working with dates and times, allowing for easy manipulation and formatting of appointment schedules.

SweetAlert2: v11.x
Provides customizable alert dialogs for better user experience when confirming, canceling or notifying users about their appointments.
